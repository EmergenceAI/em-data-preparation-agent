# Support

Thank you for using our project! We want to ensure you have the best experience possible. Please follow the guidelines below to get help.

## Community Support

For questions, troubleshooting, or general discussion, please join our community on Slack.

1. **Join the Slack Workspace:** [https://link.emergence.ai/communityslack](https://link.emergence.ai/communityslack)
2. **Join the Channel:** Once you are in the workspace, join the **#data-preparation-agent** channel.

### What to Expect
Support in the Slack channel is provided on a **best-effort basis** by maintainers and community members. While we strive to be as responsive as possible, please keep in mind:
* Response times may vary based on timezone and availability.
* Providing a clear description of your issue (and logs, if applicable) helps us help you faster.

## Reporting Bugs
If you believe you have found a technical bug, please [open an issue](https://github.com/EmergenceAI/em-data-preparation-agent/issues) on GitHub.

## Security Issues
Please do not report security vulnerabilities through public Slack channels or GitHub issues. Instead, please [refer to our Security Policy](SECURITY.md) (if applicable) or contact the maintainers directly.
